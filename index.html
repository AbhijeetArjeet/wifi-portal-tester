📱 How to Install as PWA & Background Behavior ▼

Android / Chrome:

  1. Tap browser menu (⋮) → Add to Home screen or Install app
  2. Once installed, open from home screen — auto-login triggers immediately

iPhone / iOS Safari:

  1. Tap Share button (□↑) → Add to Home Screen
  2. ⚠️ iOS suspends PWA when backgrounded — open app when switching Wi-Fi

PWA Capabilities:

  • ✅ Works offline (cached)
  • ✅ Auto-login on app open
  • ✅ Background sync (Android Chrome only)
  • ❌ Cannot change system DNS
  • ❌ Cannot detect Wi-Fi SSID
  • ❌ iOS kills background processes
🔁 Auto-Reconnect & Anti-Ban Explained ▼

How Smart Auto-Reconnect Works:

  1. Every 2 minutes (and on network changes), the app pings connectivitycheck.gstatic.com
  2. If it responds 204 → internet is open (mobile data/open Wi-Fi) → login is skipped
  3. If it fails → captive portal detected → login is auto-triggered
  4. When you switch to a campus Wi-Fi at a different building, this auto-detects and logs in

Anti-Ban (30s cooldown): Login attempts are throttled — minimum 30 seconds between attempts to prevent server bans.
